What is Nano Banana?

Four Gemini image models share the name. We use Nano Banana 2.

Model

Model ID

Best for

Status

Nano Banana 2

gemini-3.1-flash-image

The generalist. Handles 4K, text rendering and several reference images.

CURRENT

Nano Banana 2 Lite

gemini-3.1-flash-lite-image

The fastest and cheapest. It is not built for multiple reference images or multi-turn editing.

CURRENT

Nano Banana Pro

gemini-3-pro-image

The premium tier, for complex visual work where brand consistency matters.

CURRENT

Nano Banana

gemini-2.5-flash-image

The original. Google recommends moving to 2 Lite. It shuts down on 2 October 2026.

LEGACY

ai.google.dev/gemini-api/docs/image-generation · firebase.google.com/docs/ai-logic/models · ai.google.dev/gemini-api/docs/deprecations

Firebase AI vs Genkit vs Vertex AI

They differ in where your code runs.

Option

Where the code runs

Needs Firebase

Choose it when

Firebase AI Logic

WE USE THIS

In your Flutter app, through firebase_ai.

Yes

You want the shortest path from Flutter to Gemini.

Genkit

On a server you deploy. Dart, TypeScript, Go or Python.

No

You need flows and tool calling on a server.

Vertex AI

NOW AGENT PLATFORM

On Google Cloud, behind your own backend.

No

Blaze, if you go through AI Logic.

You need region pinning, throughput or Cloud Storage.

Can I use free tier?

Image generation is paid tier only.

Model

Free tier

Paid tier

Nano Banana 2

gemini-3.1-flash-image

NOT AVAILABLE

$0.50 per 1M input tokens. Images run $0.045 at 0.5K, $0.067 at 1K, $0.101 at 2K and $0.151 at 4K.

Nano Banana

gemini-2.5-flash-image

NOT AVAILABLE

$0.30 per 1M input tokens. $0.039 per image.

💡

Pro tip! Spend caps sit on the billing account, not the project: $250 on Tier 1, $2,000 on Tier 2, $20,000 to $100,000 on Tier 3. When an account hits its cap, every linked project stops until the 1st of the next month.

On the free tier Google uses your prompts to improve its products. On the paid tier it does not.

ai.google.dev/gemini-api/docs/pricing · ai.google.dev/gemini-api/docs/rate-limits

Where to put API key?

Nowhere. There is no Gemini API key to ship.

•  Google signs the calls for you.

•  App Check guards your endpoint.

💡

Pro tip! The apiKey in firebase_options.dart is a Firebase key and belongs in your code.
